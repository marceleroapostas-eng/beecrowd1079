# Beecrowd 1079 - Médias Ponderadas

## Descrição

O programa lê um número inteiro N e, para cada caso de teste, lê três valores reais e calcula a média ponderada utilizando os pesos 2, 3 e 5.

## Tecnologias utilizadas

- Java
- NetBeans
- Maven

## Entrada

A primeira linha contém um número inteiro N.

Cada uma das N linhas seguintes contém três valores reais, com uma casa decimal cada.

## Saída

Para cada caso de teste, o programa deve imprimir a média ponderada dos três valores, com uma casa decimal.
